# Genomic-Selection-Breeding-Model-for-Brassica-napus
A genomic selection breeding model for Brassica napus, integrating genome-wide markers and multi-environment phenotypic data to predict breeding values, optimize parent selection, and accelerate the development of superior cabbage-type rapeseed varieties.
本项目基于甘蓝型油菜NAM群体，构建了融合基因组标记与环境因子的油菜基因组设计育种模型。模型可针对开花期、含油量、千粒重等重要农艺性状进行预测，实现了油菜材料的早期精准筛选与育种值评估，为油菜高效育种提供技术支撑。技术路线遵循“数据获取—数据预处理—模型构建—效果验证—育种应用”完整流程（图1）。首先收集油菜核心种质的基因型数据、多年多点表型数据及环境因子数据（气温、降水、日长、积温和太阳辐射），完成基因型质控、表型校正与环境因子标准化；随后构建 GBLUP、rrBLUP、BayesA、RF、DeepGS、GWAS+PRS及加入环境因子（add_env）等7类预测模型；通过十折交叉验证评估精度，筛选最优模型；最终将模型与育种流程结合，形成可落地的基因组设计育种方案。模型预测效果表明，加入环境因子的模型在产量、含油量、开花期等3个关键性状上，预测相关性（r）显著优于无环境传统模型（图2）。对比结果显示，融合环境因子可有效降低环境噪声干扰，提升多环境下育种值预测稳定性，预测精度提升明显(在春环境开花期达到0.9765，在半冬环境开花期达到0.8722，在千粒重达到0.9134，在含油量达到0.8582)，为复杂性状的精准选择提供可靠依据。基因组设计育种应用以该模型为核心，形成标准化路径（图3）：从候选育种材料出发，经基因型鉴定与模型预测，获得个体预测育种值；依据育种值筛选优异亲本，开展组合配置与群体设计；结合田间选择快速培育新品种。整套流程缩短育种周期、提高选择效率，实现从经验育种到精准育种的转变。
相关成果属于重庆市技术创新与应用发展重点专项（CSTB2024TIAD-KPX0025）。
